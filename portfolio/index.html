Sistema de Alerta Precoce para Hiperlactatemia Pós-Operatória

O projeto desenvolveu um sistema inteligente para prever precocemente a hiperlactatemia — condição caracterizada pelo aumento anormal do lactato no sangue, geralmente associada a maior risco de complicações — em pacientes no pós-operatório de cirurgias cardíacas. Utilizando técnicas de machine learning aplicadas aos dados clínicos coletados nas primeiras horas após a cirurgia, o sistema busca auxiliar a equipe médica na identificação rápida de pacientes em risco, contribuindo para intervenções mais ágeis e precisas.

    Feito com as seguintes tecnologias:

  • Machine Learning - numpy, pandas, sklearn;
  • Backend - Python/Flask;
  • Banco de dados - Mysql;
  • Frontend - HTML, CSS, JS.

Monitoramento IoT de Ambiente Hospitalar

Este projeto desenvolveu uma solução em IoT para monitoramento em tempo real de parâmetros ambientais (temperatura e gases) em centros hospitalares, melhorando o atendimento médico e promovendo uma saúde mais conectada e sustentável.

    Feito com as seguintes tecnologias:

  • Plataforma - Node MCU/ESP8266;
  • Linguagem - C++;
  • Sensores - MQ-2,DHT22.
